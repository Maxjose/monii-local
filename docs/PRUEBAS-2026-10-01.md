## Hallazgo pendiente: BCV automático
La consulta real a COP entregó **3312,84 COP/USD**, vigente el 1 de octubre de 2026.
BCV entregó **866,56120000 Bs/USD** con fecha de valor **2 de octubre de 2026**. Monii la rechazó porque la regla actual prohíbe aplicar tasas futuras. La consulta conjunta no completó ambas actualizaciones.

Esto limita BCV cuando la página publica por adelantado la tasa del día siguiente. Se conserva la tasa previa; sin una tasa anterior puede requerir configuración manual. No se cambió la regla financiera.

**Decisión a revisar:** guardar la tasa anunciada como pendiente y aplicarla cuando comience su vigencia. Hace falta estudiar cómo obtener la tasa vigente cuando BCV reemplaza la portada.

La conexión inicial se bloqueó por los permisos de red del entorno; con acceso autorizado se obtuvieron las respuestas oficiales anteriores. Ese bloqueo inicial no es un fallo del programa.

## Repetir
Desde la raíz, ejecutar .tools/dotnet/dotnet.exe build Monii.slnx -c Release, seguido de .tools/dotnet/dotnet.exe run --project tests/Monii.Verification -c Release --no-build.

Para interfaz, ejecutar src/Monii.Desktop/bin/Release/net10.0-windows/Monii.exe con --data-dir apuntando a una carpeta nueva y --ui-verify a un directorio de resultados. Nunca usar una base real en este modo.

La consulta externa agrega -- --live-rates al comando de verificación; devuelve código 2 si una fuente no puede actualizar.
## Corrección del ejecutable de pruebas
Durante la consulta externa inicial, Monii.Verification lanzó una excepción no controlada al no actualizar ambas fuentes. Eso produjo la ventana de error de Windows reportada por el usuario. Era un fallo del manejo de errores del verificador. Se corrigió la consulta para finalizar con diagnóstico y código 2, y se añadió captura general de errores con código 1 y registro en consola. Repetición verificada: 175 comprobaciones aprobadas (código 0); consulta externa finaliza controladamente con código 2, sin excepción no controlada. Evidencia: artifacts/verification-error-fix-rates.txt. No se modificó Monii ni su base real.
